# Install in Microsoft Copilot

## As an agent (Copilot Studio or the Copilot app)
1. Create a new agent.
2. **Instructions:** paste the contents of [`pack/ai-visibility-skill-pack.md`](../pack/ai-visibility-skill-pack.md). If the field is limited, paste the *Operating instructions* and the skill you use most (the Blank-Square Audit), and attach the rest as a knowledge file.
3. **Knowledge:** add [`data/elements.json`](../data/elements.json).
4. Publish to yourself. Ask: *"Run the Blank-Square Audit on this page"* with the page text pasted.

Tip: Copilot is Bing-grounded. Before anything else, verify Bing has indexed your site at all — the **Cp Copilot** tile's move.
