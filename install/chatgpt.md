# Install in ChatGPT

## A. As a Custom GPT
1. **Explore GPTs → Create**.
2. **Instructions:** paste the contents of [`pack/ai-visibility-skill-pack.md`](../pack/ai-visibility-skill-pack.md). If it exceeds the field limit, paste the *Operating instructions* and *The table* sections there and upload the full file under **Knowledge**.
3. **Knowledge:** upload [`data/elements.json`](../data/elements.json) and [`data/questions.json`](../data/questions.json).
4. Save. Ask: *"Run the Blank-Square Audit on this page"* and paste the page text.

## B. As a Project
Create a Project, add the pack file and the two data files to the project files, and set the project instructions to the *Operating instructions* section of the pack.
