# Install in Gemini

## As a Gem
1. **Gems → New Gem**.
2. **Instructions:** paste the contents of [`pack/ai-visibility-skill-pack.md`](../pack/ai-visibility-skill-pack.md).
3. **Files (where supported):** add [`data/elements.json`](../data/elements.json) so the Gem can quote any element's watch-out and 2026 audit note.
4. Save. In the Gem, paste your page's text and ask: *"Run the Blank-Square Audit on this."*

Tip: test your category prompt in a signed-in Workspace account as well as the consumer app — the grounded answer differs (that is the **Ge Gemini** tile's move).
